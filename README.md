# 🎓 Voting Kakang Senduk

Website **Voting Kakang Senduk** merupakan aplikasi berbasis web yang dikembangkan untuk mempermudah proses pemilihan kontestan Kakang dan Senduk secara online. Sistem ini dirancang untuk mengelola data kontestan, proses voting, verifikasi pembayaran, serta menampilkan hasil perolehan suara secara terstruktur.

## ✨ Fitur Utama

- **Login dan Hak Akses** – Sistem autentikasi dengan dua role, yaitu Admin dan Pemilih.
- **Manajemen Kontestan** – Admin dapat menambahkan, mengubah, dan menghapus data kontestan Kakang maupun Senduk.
- **Sistem Voting** – Pemilih dapat memberikan suara kepada kontestan pilihannya.
- **Pembayaran QRIS** – Mendukung proses pembayaran menggunakan QRIS.
- **Verifikasi Pembayaran** – Admin dapat memeriksa bukti pembayaran dan menyetujui pesanan voting.
- **Hasil Voting** – Menampilkan jumlah suara, ranking kontestan, dan persentase perolehan suara.
- **Dashboard Admin** – Menyediakan informasi dan pengelolaan data voting.

| Role | Hak Akses |
|---|---|
| Admin | Mengelola kontestan, memverifikasi pembayaran, dan melihat hasil voting. |
| Pemilih | Melakukan pemilihan kontestan dan melihat informasi voting. |

## ⚙️ Instalasi

1. Clone repository ini:
   ```bash
   git clone URL_REPOSITORY_KAMU
   ```

2. Pindahkan folder project ke direktori `htdocs` XAMPP.

3. Jalankan Apache dan MySQL melalui XAMPP.

4. Buat database melalui phpMyAdmin.

5. Import file database project ke database yang telah dibuat.

6. Sesuaikan konfigurasi koneksi database pada file konfigurasi project.

7. Buka aplikasi melalui browser:
   ```text
   http://localhost/voting-kakang-senduk
   ```
